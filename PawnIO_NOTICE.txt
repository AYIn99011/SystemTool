PawnIO binary notice
====================

SystemTool bundles the unmodified official PawnIO installer as an embedded
resource. It is extracted and executed ONLY after the user explicitly agrees
in the in-app "install temperature driver" prompt shown at startup when the
driver is missing. It is never installed silently without consent.

- Product: PawnIO official edition
- Version: 2.2.0
- Publisher / signer: namazso.eu (CN=namazso.eu)
- Official release: https://github.com/namazso/PawnIO.Setup/releases/tag/2.2.0
- File: PawnIO_setup.exe (bundled as embedded resource)
- SHA-256: 1F519A22E47187F70A1379A48CA604981C4FCF694F4E65B734AAA74A9FBA3032

PawnIO is GPL-2.0 with a device-IOCTL exception for independent modules that
communicate solely through the device I/O-control interface. Redistribution
of the unmodified installer is allowed; when practical, users are directed to
https://pawnio.eu/ (see https://github.com/namazso/PawnIO.Modules/wiki/Using-PawnIO-Modules).

SystemTool verifies both the SHA-256 hash and the Authenticode signer
thumbprint before running the installer. If the bundled copy is missing or
fails verification, the installer falls back to downloading from the official
GitHub release above.
